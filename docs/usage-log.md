# Usage từng chat

Mỗi chat xong mục tiêu thì AI ghi một dòng, theo [`profile/CHATS.md`](https://github.com/thiengthb/thienai-workflow/blob/main/profile/CHATS.md). Số lấy từ skill `explain-usage`: tổng của cả chat, không tách theo việc, nên chat làm nhiều việc thì ghi rõ ở cột Mục tiêu. Đọc lại là token đọc lại từ cache (tính khoảng 0,1 lần), ghi cache tính khoảng 2 lần, viết ra khoảng 5 lần so với token thường. Các cột % là phần usage ước tính, vì usage đo theo lượt chứ không theo công cụ.
